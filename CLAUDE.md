# PCBCraft: Claude Code

The rules for every agent live in `.cursor/rules/*.mdc`; [AGENTS.md](AGENTS.md) lists the files. Start here: issue [#1](https://github.com/wdunn001/pcbcraft/issues/1) on wdunn001/pcbcraft, then [CONTRIBUTING.md](CONTRIBUTING.md).

Read `pcbcraft-pipeline.mdc` before claiming work, then the rule file for the area you edit (`pcbcraft-core.mdc`, `pcbcraft-ui.mdc`, `pcbcraft-tests.mdc`). Always follow `pcbcraft-public-repo.mdc` and `pcbcraft-docs.mdc`.
