# PCBCraft page-by-page layout

What each work area holds, region by region. The tokens, components and rules are in [design-system.md](design-system.md); this page does not repeat them. The mockups are attached to the issues in the table at the end of that page.

Frame (1920 by 1240 reference): menu bar 32, tab nav 40, tool bar 40, body, status bar 24 (the open project's name at the left with a small copper dot when it has unsaved changes, then the last plain sentence; no command names). Body = left aside 320, centre, right aside 340. The bottom sheet sits under the centre only (232 open, 36 collapsed). There is no left rail.

Each tab owns its regions through the `Workspace` trait in `crates/ui-egui/src/workspace.rs`: its tool bar, left aside tabs, centre, bottom sheet tabs and default layout. The user's layout is remembered per tab and View > Reset layout restores the defaults. The Workspace contract today lists Files, Schematic, Layout, Analyze and Manufacture; the Library tab joins it as its own workspace.

## 1. Shell

- Menu bar: brand mark and name, then File, Edit, View, Help. Nothing else (no project title, no Save and Undo buttons, no version; those are menu items and Help, About).
- Tab nav: Files, Schematic, Layout, Analyze, Manufacture, Library. These are work areas only; settings and one-off dialogs are not places you work in. The active tab has a 2 px copper bar.
- Tool bar: one row, changes per tab (listed per page). No layer drop-down and no selection-filter chips on any tab; the layer is picked in the Layers tree and picking is limited by locking rows. Buttons centre their icon and label.
- Status bar: document state left; error and warning counts (a click opens the bottom sheet on Findings), cursor X Y, units and zoom right. Nothing else.
- Bottom sheet: Findings (Run checks, severity filter, rows), Output (progress and results of the last run), Console (developer detail lives here), Parts (one row per part with reference, value, footprint, maker and part number; header buttons sort, a filter box per column narrows the rows, and a cell edit is one undo step; the boxes at the left pick rows, Shift picks a range, and Fill writes one typed value into a chosen column of every picked row as one undo step; Export saves the grid as a spreadsheet file with the visible columns, order and filter; Group identical merges parts the bill of materials prints as one line and adds a Quantity column; Layout columns, off by default, adds the read only Side, Rotation, Locked, X and Y of each placed part after Part number and is hidden while Group identical is on). Collapsed it is a 36 px tab strip with a count. Open, drag its top edge to make it taller or shorter: it stops at 120 px and at 70 percent of the window height, and it keeps the height you dragged to (once for Parts, once for the other tabs) when you fold and reopen it.
- Right aside: Properties | Assistant on every tab that has one. Content padding is 12 on all sides.

## 2. Pages

### Files
Its own workspace, drawn as the `files` mockup. Tool bar: New, Open, Save | Import, Export | Open sample project (icons only in a narrow window). Left aside: the project files tree with Files and History tabs. The Files tab has a filter box, then the sections Design (the design file, marked Unsaved changes while it has changes), Project library (Symbols, Footprints, 3D models), Attached files (Datasheets, Notes, Images), Made files and History, each with a count. A section with no data source yet says so in one row (Nothing made yet). The Layout layers tree is never shown here. Centre: the project name in display size with its saved state, four cards (Parts, Nets, Board shape, Checks) that each end in a link to the tab where the card belongs (Open in Schematic, Edit shape in Layout, Open Findings), a Shape of each layer row with one small drawing per copper layer (Follows the board or Own shape), Next (fix errors, make files, save a copy to share) and Recent projects. The Board shape card draws the cut path with its cut-outs and mounting holes and prints the corner, cut-out and mounting hole counts and the read only reach (`Reaches W x H mm`). Saving, opening and adding files are done only from the tool bar, never from buttons inside the page. Open, Import and Export open as pages under a Back to project button. Right aside: project Properties with General (name, units, author, notes), Shape (outline kind, corners, the read only reach with the hint that you change the shape and not the box, Edit shape in Layout, Replace from SVG or DXF, Start from a rectangle), Layers (copper layer count, Stackup and finish) and a Project settings button. The board is a free-form 2D cut path. A rectangle is only a template: Start from a rectangle asks for a width and a height in a small dialog and is the only place the two numbers appear. There is no Width or Height field on the page and no Library sources button; library sources belong to the Library tab.

### Library
A full workspace for parts. Part browser with search and the Symbols | Footprints | Both segmented filter; part pages that open as tabs; a datasheet reader per component; vendor prices and supplier sources with editing; create and edit parts with symbol and footprint editors and 3D models; a Compare view that diffs the specs of two to five parts. A link that used to open settings opens the part in this tab instead.

On the Collections page, Load library and Save library open a small chooser window with Up, Home, a path box and a list of folders and collection files. Load library takes a collection file and says on the page how many symbols and footprints came in, or why the file would not load. Save library takes a folder and a file name. On the Sources page, Choose folder opens the same chooser to pick a folder of collections, and the card says what was added and how many collections were found, or why not. The typed folder box stays for pasting a path. The browser build has no folder access, so there Load library and Load collection file pick a file with the browser's own picker and Save library downloads the file. Linking a folder of collections as a source in the browser is not built yet.

In the part browser, the connector series from the built-in catalog are listed under a heading that names the maker, even with an empty search and no filter. Turning on the Connectors switch, or typing the maker or a series name, keeps the same rows and hides them under any other kind switch. Each row shows the series, a line saying what it is, the pitch and the range of positions, all read from the catalog. A series is a family you configure and not a single part number, so the row has no drawing until you choose a size. Picking a row opens its choices: rows, positions per row, the lead or stack code and alignment posts. The part number shows as you choose, and Place on schematic (Place on board on the Layout tab) puts the generated connector in the design with its symbol and footprint added to the project library. One undo takes the whole placement back.

### Schematic
Tool bar: Select | Add (Label, Power symbol, Bus, Port, No connect, Pad; placing repeats until Esc) | Measure. While Label is armed a small panel over the sheet takes the net name to type: a name already in use joins that net and a new name makes one, so two labels of one name share a net, and a design that opens with nets of one name has them merged with a notice and one undo step. While Power is armed the panel takes the net (such as 3V3) and a style: ground, bar, arrow or negative; the power checks treat that net as driven. There is no Wire, Place part or Move button: a press on a pin starts a wire, library cards drag onto the sheet, and a drag moves a part, and a drag on a power symbol or a net label moves it too (snapped to the grid, one Undo). A selected label or power symbol shows its net name in Properties: type a new name and press Enter, and a name already in use joins that net while a new name makes one; a power symbol also takes a style there. Left aside Layers | Library. The Layers tab is the sheet tree: the first page (Main until renamed) with Symbols, Net labels, Power symbols, Buses, Text and notes and Drawing, then Parts and Nets. Net labels and wires belong to their net. Centre: a fitted sheet with zone border, grid, symbols with pin numbers, junctions, power symbols and title block. Each schematic page is its own schematic: a new page is empty, and a page draws, picks, snaps to and lights only its own parts, wires, labels, ports and text. The Main page is the one exception: it is the top level of the design. Each other page that has items shows on Main as one part named after the page, with one pin for each public net of that page (a net that has a port, a power symbol or a global label on the page; private nets have no pin). Wire a pin of a Main part to a pin of a page part and that pin joins the net on the page. A toggle on the page part opens that page up, and Open all pages in the tool bar opens every page; both are off by default, are not saved in the file, and an open page shows its items on one continuous sheet that lays the pages side by side, left to right, about 20 mm apart and top aligned, with one frame and one title block and no panel per page. Each item still belongs to its own page. A click on a part of an open page selects it, but Main does not change it: a drag, a Properties edit or a delete is refused with a note to open that page. A page drawn as a box on its parent keeps that box. Main keeps parts of its own beside the pages: parts, labels and wires placed on Main belong to Main and can be moved there. A page has one name, shown in the tab strip, as the TITLE of its title block, in the Layers tree and as the Title field of the page Properties; rename it in any of them. The title block is not a row: it is a section of the page Properties (Title, Revision, Date, Sheet size, Company, Drawn by, Show title block), and each box holds the text the sheet paints. The block also prints the project name and "2 of 3" for the sheet number. Right aside: Properties of the selection. Bottom sheet collapsed with the findings count.

### Layout
Tool bar: Select, Route, Via, Zone, Keepout, Outline, Text, Measure | Corners (45, 90, Free), Width. The layout syncs from the schematic automatically; Edit > Update layout from schematic runs it by hand.

Left aside Layers | Library. The Layers tree is the centrepiece:
- search field, New layer, Show all, Hide others
- Copper (Top and Bottom copper with pads, tracks, zones), Silkscreen, Mask and paste, Board (outline locked, mounting holes), Courtyards, User layers
- Parts (each expands to pads) and Nets (colour, pad count; a net expands to its wires, tracks and vias)
- every row: chevron, swatch or icon, name, count, lock, eye; hidden and empty rows dim; every row has a tooltip that explains what it is
- a hidden row paints nothing and cannot be hovered, clicked, boxed, snapped to or routed from: the Board edge eye owns the board fill, outline, cut-outs, datums, dimension lines and outline handles; the Drills and vias eye owns mounting holes, slots and vias; a Top or Bottom eye owns its parts, pads, tracks and zones; each drawn layer has its own eye. Show all brings every eye back and Hide others keeps only the picked row. Picking a row's child in the tree still selects it so it can be found and shown again
- on the Schematic tab the Layers aside has the filter box and the Show empty toggle only; Show all, Hide others and New layer belong to the Layout tab, and pages are added from the page strip above the canvas

Selecting a row sets what the tools draw on. Hover previews a layer; a click pins it until you click again, press Esc or Reset. Page Up and Page Down step through sublayers. The full rules are in design-system.md, section 11.

Centre: board with chamfered corners, Y up with rulers and axis gizmo, dimensions, ratsnest, selection handles. The Layout view card at the top right holds 2D | 3D, Top | Bottom, rotate left, rotate right and reset. On 3D the canvas shows the board and parts with a soft shadow, the tool bar offers Orbit, Pick part, Measure and Export 3D model, and the Layers tree eyes drive visibility. Right aside: Properties. The top row of the Layers tree is the Board shape, described as "Rectangle, 4 corners" or "Free-form, 20 corners" with no width and height. A copper layer may have a shape of its own: its row carries an Own shape tag, and its menu and Properties offer Give this layer its own shape and Follow the board shape. The outline handles edit the shape of the active copper layer, or the board shape when that layer follows it; the footer says which. The active layer's shape is drawn solid, the board shape dimmer, and the other layers' own shapes as dashed outlines in their layer colours. Silkscreen, mask and paste follow the shape of their copper layer and are not clipped to it on the canvas. Shape Properties show Outline, Corners, Cut-outs and a read-only Reaches, with Start from a rectangle (the one place a width and a height are typed) and Replace from SVG or DXF. Board settings (the board row of the Layers tree) holds a Shape section (preset buttons for rectangle, rounded rectangle, circle, ellipse, polygon, L shape and chamfered rectangle, the sizes of the picked preset, and the live area and size of the outline), then the stackup. Bottom sheet open on Findings.
Draw shape: the right aside opens with a Drawing on chip (layer, purpose, one sentence on what a figure there becomes). The status bar names the shape, the layer and its purpose before the first click, and while a line, box or circle is pending the canvas shows its length and angle, width and height, or radius beside the pointer.

### Analyze
A sixth work area, approved in issue #1421, between Layout and Manufacture. It holds checks, signal and power analysis, instruments and rules. Tool bar: one row that follows the showing page (Run selected and Stop, then Export CSV; the Scope page has Run, Stop, Single | Probe, Cursors, FFT | Export CSV, Export image). Left aside, titled Analyses: a filter box with an add button, Run all and Mute all, then the groups Checks (Design rules, Electrical checks, Placement), Signal integrity (Impedance targets, Return path, Crosstalk, Reflections and levels, Eye diagram), Power integrity (Rails, PDN impedance, Load step), Protocols (UART, SPI, I2C, CAN), Instruments (Scope, Firmware, Hardware link, IDE link, RF, Antenna) and Rules (Rule sets, Net classes). Each row has a status dot, its name and, only where the design backs one, a count. The picked row has the copper bar. Centre: the page of the picked row as cards. Right aside: Properties of the page, in captioned sections of label and value rows.

The ten pages are Scope, Checks, Net classes, PDN impedance, Reflections and levels, RF, Antenna, Firmware, Hardware link and IDE link. Placement, Impedance targets, Return path, Crosstalk, Eye diagram and Rails have no page yet and open one plain page that says so; Rule sets opens a page with a button to the Rules page; the four protocol rows and Scope open the Scope page; Load step opens the PDN page.

Three pages read real data. Scope opens with a Probes card: a table of the design's virtual probes with the label, the point, the net each is measured against and its DC voltage, a Remove button per row, and, with no probe, the plain line that says to place one on the schematic. Probes are put on the schematic with the Probe tool on the tool bar (click a pin or a wire, Esc to stop), and each shows a small badge with its label and voltage. The voltages come from the same DC solve as the `sim.dc` command, run once per design change; when it cannot run the card says why and shows no number. The rest of the Scope page, the waveform, is not built. Checks lists the findings of the design's own checks, the same list as the Findings tab, with Show and Mute on each row and a card that reads the fix hint of the shown finding. Net classes lists the design's net classes and opens Project settings on its Net classes tab to change them. Every other page draws its cards and Properties sections as the mockups lay them out, with a plain empty state in each card that says what is missing and, where a tab will produce the data, a button that opens it. Properties rows on those pages read Not set. A button with nothing behind it is disabled and its tooltip says why. No waveform, curve, number or status is drawn that the design did not produce.

### Manufacture
A CAM and outputs workspace. Tool bar: Generate all (primary), Add output, Panelize | Machine picker, Run, Export | Preview toggle | stale count. Left aside Outputs | Machines. The outputs tree is grouped by kind: Fabrication (Gerber with a row per layer, Drill, Drill map, netlist), Assembly (parts list, placement, assembly drawing), CAM jobs (isolation milling, drilling, outline, laser, stencil, print, pick and place). Each row: name, machine, badge (Current, Stale, Not made), eye. Centre: preview of the selected output with the Show in preview checklist and the estimate card. Right aside: Properties of the output (name, machine, file name, side, tool table, feeds, depths, passes; Generate, Export, Run on machine). Bottom sheet: Output log and Findings.

## 3. Dialogs and menus

- Project settings (File menu, and the button in Files Properties): tabs Board, Design rules, Net classes, Electrical rules, Machines, Title block, Builds.
- Project settings, Board tab: a Board shape card draws the outline with its cut-outs and mounting holes beside Outline (Free-form, or a plain name such as Rectangle, 4 corners), Corners, Cut-outs and a read only Reaches width by height, with the buttons Replace from SVG or DXF, Start from a rectangle and Edit in Layout. Start from a rectangle opens a small window with a width and a height; it is the only place those two numbers are typed. A Shape of each layer card lists the copper layers, each Follows the board or has its own shape; layer shapes may differ and overlap, and the other layers follow their copper layer. The Finish card and the Stackup card sit beside and below them.
- Preferences (Edit menu): tabs Appearance, Language, Units, Keys, Assistant.
- File menu with Import and Export submenus, the Edit menu and every right-click menu: design-system.md, section 8.
